# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep
discussions about the project. Harassment, personal attacks and
discriminatory language are not tolerated.

Specific to this project: **do not share or ask for other people's mushroom
spots or private locations.**

To report unacceptable behaviour, use GitHub's private vulnerability
reporting channel (see [SECURITY.md](SECURITY.md)) or contact the maintainer
through their GitHub profile. Reports are handled confidentially, following
the Covenant's enforcement guidelines.
